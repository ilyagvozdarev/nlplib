
    '''
        извлекает текст и спикеров из диаризированного текста

        Parameters
        ----------
        diar_text:
            диаризированный текст ('*spk_token* текст спикера *spk_token* текст спикера ...')

        DC:
            конфиг диаризации с speaker_prefix, speaker_suffix используемых
            для определения что токен является токеном спикера
        
        skip_meaningless_speaker:
            нужно ли пропускать (заменять на прошлого спикера) невалидные 
            (пустые или не циферные) имена спикеров. Если False - то будет исключение
    
        Returns
        -------
        # можно указать тип возвращаемого значения или названия переменной (если она есть)
        list[dict]: 
            сегменты диаризации - список словарей вида:
            {
                "speaker": спикер,
                "text": текст
            }
        
        Yield
        -------
            ...
        
        Notes
        -----
        - имена спикеров должны быть целыми числами
        - если токен начинается с speaker_prefix но не заканчивается speaker_suffix,
          то speaker_suffix добавляется к токену
        - в случае если первый спикер является невалидным, то считается что прошлый 
          спикер имеет имя '1'
        - диаризированный текст вначале разбивается по пробельному символу,
          поэтому в итоговом текста все непрерывные последовательности пробельных
          символов будут заменены на 1 пробел
    '''
