считываем конфиг обучения

- оборачиваем в unsloth:
    model, tokenizer = FastLanguageModel.from_pretrained(
        model_name=config["model_name"],
        max_seq_length=max_seq_length,
        dtype=torch.bfloat16,
        load_in_8bit=config["load_in_8bit"],
        load_in_4bit=config["load_in_4bit"],
        attn_implementation="flash_attention_2",
    )

- задаем параметры токенизатора:
    tokenizer.bos_token = config["bos_token"]
    tokenizer.eos_token = config["eos_token"]
    tokenizer.pad_token = config["pad_token"]
    tokenizer.padding_side = "left"


- если в конфиге обучение есть ключ lora то оборачивает в peft-модель:
    model = FastLanguageModel.get_peft_model(
        model, **config["lora"], max_seq_length=max_seq_length
    )

- считываем train/val датасеты (аргументы CLI) и формируем для них DPODataset



- обучение:
    training_args = DPOConfig(
        output_dir=output_dir, report_to="wandb", **config["dpo"], **trainer_config
    )

    trainer = DPOTrainer(
        model=model,
        ref_model=None,
        args=training_args,
        processing_class=tokenizer,
        train_dataset=train_dataset,
        eval_dataset=eval_dataset,
    )

    trainer.train()
