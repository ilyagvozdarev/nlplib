формирует train/val датасеты из исходного датасета/списка датасетов (split="train") 
(из конфига датасета | "IlyaGusev/saiga_scored") с предобработкой и фильтрацией

CLI:
  config_path         конфиг
  train_path          путь сохранения train
  val_path            путь сохранения valid


config:
  dataset_name        датасет/список датасетов  (id в репозитории)
  dataset_revision    
  field_mapping
  sources
  chosen_models
  exclude_regex
  max_length_ratio
  max_length_ratio_prob
  sonnet_approved_only


-----------------------------------------------

- загружаем конфиг датасета (аргумент CLI)
- загружаем датасет/датасеты (split=train) ("dataset_name" из конфига датасета | "IlyaGusev/saiga_preferences")

предобработка и фильтрация:
	- переименовываем столбцы если в конфиге датасета задан field_mapping (конфиг датасета)
	- оставляем только строки датасета у которых столбец source содержится в sources (конфиг датасета)
	- оставляем только строки датасета у которых столбец chosen_model содержится в chosen_models (конфиг датасета)
	- пропускаем строки датасета у которых is_bad_by_regex равен True если exclude_regex равно True (конфиг датасета | False)
	- если длина строки chosen больше чем rejected в max_length_ratio (конфига датасета | 2.1) раз то пропускаем пример с вероятностью max_length_ratio_prob (конфиг датасета | 0) 
  	  (видимо чтобы модель не смещалась в сторону более длинных ответов)
	- оставляем строки только у которых sonnet_approved равен True если sonnet_approved_only == True (конфиг датасета | False) 
	- пропускаем строки с пустым chosen или rejected
	- fixt_text:
    		"\xa0" -> " "
    		\\xa0 -> " "
    		strip
	- роль bot -> assistant
	- перемешиваем (random.shuffle)

	- делим на train/val в отношении 97/3. в train все примеры для которых остаток от деления хэша полученного библиотекой mmh3 на 100 меньше 97, в val - больше.
	  Так одинаковые примеры будут попадать в один и тот же набор и не будет утечки данных

сохраняем в ..._train.jsonl ..._val.jsonl (аргументы CLI) (json 1 пример в 1 строке)
