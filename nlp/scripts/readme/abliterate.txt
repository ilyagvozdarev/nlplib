get_harmful_instructions

	формирует список вредных инструкций из датасета mlabonne/harmful_behaviors + константные примеры:

	- загружаем датасет (train, test) с текстами вредных инструкций mlabonne/harmful_behaviors
	- преобразуем тексты инструкций в 1-turn разговоры с ролью user (reformat_texts)
	- добавляем к train и test несколько константных примеров на русском



get_harmless_instructions

	формирует список безвредных инструкций из датасета mlabonne/harmless_alpaca + константные примеры:

	- загружаем датасет (train, test) с текстами безвредных инструкций mlabonne/harmless_alpaca
	- преобразуем тексты инструкций в 1-turn разговоры с ролью user (reformat_texts)
	- добавляем к train несколько константных примеров на русском
