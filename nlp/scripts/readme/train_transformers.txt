

отличия от train_unsloth:

    можно задать токенизатор (в unsloth используется тот который возвращается FastLanguageModel)

    data_collator = DataCollatorForTokenClassification(tokenizer, pad_to_multiple_of=8)

    нет:
      os.environ["UNSLOTH_RETURN_LOGITS"] = "0"           # чтобы Unsloth возвращал логиты
      os.environ["TOKENIZERS_PARALLELISM"] = "false"      # чтобы предотвратить предупреждения в токенизаторах Huggingface
      torch._dynamo.config.cache_size_limit = 128

    не проверяем связывание входных и выходных эмбеддингов для их связывания в peft-модели

    вызываем unsloth.models._utils.prepare_model_for_kbit_training перед оберткой в peft

    оборачиваем в peft модель методом peft.get_peft_model а не FastLanguageModel.get_peft_model

    не переопределяем create_optimizer (то есть lr одинаковый для всех модулей)
